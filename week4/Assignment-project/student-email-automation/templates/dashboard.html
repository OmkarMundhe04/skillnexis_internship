How to Host This Tool on Render (100% Free)

Connect your existing GitHub repository and deploy your live web dashboard in under 3 minutes.
Recommended: Free Forever
1

Push Your Latest Code to GitHub

Your workspace is already linked to your GitHub repository: https://github.com/OmkarMundhe04/skillnexis_internship.

git add .
git commit -m "Add web dashboard and cloud hosting configuration"
git push origin main
2

Create a Free Web Service on Render

  1. Go to Render.com and sign up or log in (1-click with GitHub).
  2. Click New + and select Web Service.
  3. Connect your GitHub repository skillnexis_internship.
3

Configure the Service Settings

Root Directory week4/Assignment-project/student-email-automation
Runtime Python 3
Build Command pip install -r requirements.txt
Start Command uvicorn app:app --host 0.0.0.0 --port $PORT
Instance Type Free ($0/month)
4

Add Your SMTP Environment Variables Securely

Under the Environment Variables section on Render, add:

SENDER_EMAIL = your-email@gmail.com
SENDER_PASSWORD = your-16-char-app-password
SMTP_SERVER = smtp.gmail.com
SMTP_PORT = 587
DRY_RUN = true (or false for live)
5

Click "Create Web Service"

Render will automatically build your app and give you a public URL like https://student-email-automation.onrender.com. You can now access your dashboard and send emails from any browser or phone!
